# RED FLAGS & EMERGENCY PIVOTS

## If You See These, Pivot Immediately

```
RED FLAG #1: "Zero signups after 10 days"
├─ Cause: ProductHunt launch failed OR product broken OR market doesn't care
├─ Action: 
│  ├─ Check: Is product working? (test yourself)
│  ├─ Check: Is marketing reaching anyone? (check analytics)
│  ├─ Fix: Relaunch with different angle (urgent)
│  └─ If still zero: Pivot to Freemium (lower commitment barrier)

RED FLAG #2: "Signups high (100+) but 0% doing lookups"
├─ Cause: Signup flow works but product doesn't deliver value
├─ Action:
│  ├─ Record user session: Watch someone use the product
│  ├─ Identify: Where do they abandon? Why?
│  ├─ Fix: Product gap, confusing UX, or positioning mismatch
│  └─ Relaunch: "Here's how it actually works" (Day 1 better onboarding)

RED FLAG #3: "5+ demos scheduled but 0% conversion"
├─ Cause: Demo people interested but offer/positioning wrong
├─ Action:
│  ├─ Analyze: What's the objection? (too expensive? not quite right?)
│  ├─ A/B test: Try $1K pricing instead of $1.5K (or test other benefits)
│  ├─ Re-pitch: Show specific ROI (money saved, hours saved)
│  └─ If still zero: Pivot pricing model (monthly instead of annual? Freemium?)

RED FLAG #4: "0 sponsor interest after Tier 1 targeting"
├─ Cause: Sponsors either don't believe volume or ROI story wrong
├─ Action:
│  ├─ Interview: Call 1-2 prospects who didn't respond
│  ├─ Ask: "If we had 5K contractors/month, would you sponsor?"
│  ├─ If YES: Problem is credibility. Get direct customers first (proof).
│  ├─ If NO: Problem is positioning. Try different sponsors (Tier 2).
│  └─ If 0/5 say yes: Sponsor model may not work. Pivot to direct sales.

RED FLAG #5: "Week 3 and still no paying customers"
├─ Cause: Either product isn't ready OR sales motion broken
├─ Action:
│  ├─ Decision point: Do we fix product or fix sales?
│  ├─ Quick test: Offer 3-month trial at 50% off to next 5 demos
│  ├─ If 2+ say yes: Sales motion works, pricing just high
│  ├─ If 0/5 say yes: Product gap. Fix before continuing.
│  └─ Emergency: Pivot to Freemium (free > trial conversion 10x better)

RED FLAG #6: "Founder burnout (50+ hours/week by Week 2)"
├─ Cause: You're doing everything (sales, support, ops, product)
├─ Action:

│  └─ If budget tight: Ask advisor for intro to fractional hire (often discounted)

├─ Cause: Losing belief in product/market/plan
├─ Action:

│  ├─ Advisor call: Talk to trusted advisor (1 hour)
│  ├─ Sanity check: Is this a timing/execution problem or market problem?
│  ├─ Decision:
│  │  ├─ Timing/execution: Fix + continue (this week)

│  │  └─ Personal: Take break, come back refreshed (no shame in this)
│  └─ Document: What would need to be true for you to believe again?
```
